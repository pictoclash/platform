The blobs directory contains paint blobs. They are derived from a containers typeface called Irregardless Containers, where letters code for container objects, like paint blobs, boxes, badges, wooden planks, et cetera.

The files are named by their corresponding letter code.

The following letters code for the following symbols:

a: speech bubble, no tail, yell
b: cloud blob
c: flag
d: paint blob
e: paint blotch
f: marker coverings
g: spiky inner radius bubble
h: flower blob, low petals
i: flower blob, high petals
j: speech bubble, no tail
k: badge, spikes in cardinal directions
l: scratch pattern
m: folded paper
n: flower blob, spiky petals
o: speech bubble, no tail, expletive, low spikes
p: speech bubble, no tail, expletive, high spikes
q: four planks
r: badge, inverse rounded corners
s: mold spore
t: paint blotch, with splatters
u: wooden plants, broken off
v: speech bubble, tail left
w: speech bubble, tail right
x: thought bubble, tail left
y: thought bubble, tail right
z: popping balloon
